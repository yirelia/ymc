# S1 文法对照表：MLS 3.6 附录 B ↔ ymc 解析器 ↔ Absyn

方案 §5 S1 承诺的"文法逐条对照表"。左列是 MLS 3.6 附录 B 的产生式（按 B.2.1–B.2.7 分节），
中列是 `src/parse/parser.cpp` 里对应的函数，右列是结果落到 `src/absyn/absyn.h` 的哪个类型。
末节列出 **ymc 有意偏离 MLS 字面、跟随 OMC 实际接受文法** 的地方（本项目验收对象是 OMC testsuite，
方案 §3.6：来源三选一，这里的来源是 `OMCompiler/Parser/Modelica.g` 与 testsuite 实跑）。

读法建议：先看 §B.2.7（表达式），它最小、最自包含；再看 B.2.4/B.2.5（元素/修饰）；最后 B.2.2（类）。

## B.2.1 stored_definition

| MLS 产生式 | 解析函数 | Absyn |
|---|---|---|
| `stored_definition = [within [name] ";"] { [final] class_definition ";" }` | `parse_program` | `Absyn::within_path/top` |

顶层每个类定义后的 `;` 是必需的；缺失时在 EOF 处报错（EOF 记号列记 0，对齐 OMC 的 `line:0`）。

## B.2.2 class_definition

| MLS 产生式 | 解析函数 | Absyn |
|---|---|---|
| `class_definition = [encapsulated] class_prefixes class_specifier` | `parse_class_definition` | `ClassDef` |
| `class_prefixes = [partial] (class \| model \| [operator] record \| block \| [expandable] connector \| type \| package \| [pure\|impure] [operator] function \| operator)` | `parse_class_prefix` | `ClassDef::restriction`（`Restriction` 枚举）、`is_partial/is_encapsulated` |
| `long_class_specifier = IDENT description_string composition end IDENT` | `parse_class_definition` + `parse_composition` + `parse_class_end` | `ClassDef::name/string_comment/elements/...` |
| `long_class_specifier = extends IDENT [class_modification] description_string composition end IDENT` | 同上，`match(Kw_extends)` 分支 | `ClassDef::is_class_extends/class_extends_mod` |
| `short_class_specifier = IDENT "=" base_prefix type_specifier [array_subscripts] [class_modification] description` | `parse_short_class_body` | `ClassDef::is_short/short_prefix/short_type/short_subscripts/short_mod` |
| `short_class_specifier = IDENT "=" enumeration "(" ([enum_list] \| ":") ")" description` | `parse_short_class_body`（`Kw_enumeration` 分支） | `ClassDef::is_enumeration/enum_unspecified/enum_lits` |
| `der_class_specifier = IDENT "=" der "(" type_specifier "," IDENT {"," IDENT} ")" description` | `parse_short_class_body`（`Kw_der` 分支） | `ClassDef::is_der/der_fn/der_vars` |
| `composition = element_list { public element_list \| protected element_list \| equation_section \| algorithm_section } [external ...] [annotation ";"]` | `parse_composition`（记住当前段，注解后回到该段继续） | `ClassDef::elements/initial_equations/equations/algorithms/has_external/annotation` |
| `external_clause = external [language_specification] [external_function_call] [annotation] ";"` | `parse_external` | `ClassDef::ext_lang/ext_lhs/ext_call/ext_annotation` |
| `end IDENT` 首尾一致 | `parse_class_end` | —（不一致：报在类头名字处，同 OMC Modelica.g:361） |

| MLS 产生式 | 解析函数 | Absyn |

## B.2.4 component_clause

| MLS 产生式 | 解析函数 | Absyn |
|---|---|---|
| `element = import_clause \| extends_clause \| [redeclare] [final] [inner] [outer] ([replaceable] (class_definition \| component_clause) [constraining_clause description])` | `parse_element` | `Element`（`kind` + 前缀布尔） |
| `import_clause = import (IDENT "=" name \| name ["." ("*" \| "{" import_list "}")]) description` | `parse_import` | `Import`（`Element::imp`；`multi/multi_alias`） |
| `component_clause = type_prefix type_specifier [array_subscripts] component_list` | `parse_component_clause` | `ComponentClause` |
| `type_prefix = [flow\|stream] [discrete\|parameter\|constant] [input\|output]` | `parse_type_prefix`（严格顺序、各至多一个） | `TypePrefix` |
| `type_specifier = ["."] name` | `parse_name_path` | `ComponentClause::type_leading_dot/type_path` |
| `component_list = component_declaration {"," component_declaration}` | `parse_component_clause` 内循环 | `ComponentClause::comps` |
| `component_declaration = declaration [condition_attribute] description` | 同上 | `ComponentDecl`（`condition` 为 `if expr`） |
| `declaration = IDENT [array_subscripts] [modification]` | 同上 + `parse_array_subscripts` + `parse_modification_opt` | `ComponentDecl::name/subscripts/mod` |
| `component_clause1 = type_prefix type_specifier component_declaration1`（修饰里的 redeclare） | `parse_component_clause(single_decl=true)` | 同上（只一个声明，逗号属外层） |

## B.2.5 modification

| MLS 产生式 | 解析函数 | Absyn |
|---|---|---|
| `modification = class_modification ["=" modification_expression] \| "=" modification_expression \| ":=" modification_expression` | `parse_modification_opt` | `Modification`（`args` + `binding` + `assign`） |
| `modification_expression = expression \| break` | `parse_modification_expression` | `Id<Exp>`（`ExpKind::Break`） |
| `class_modification = "(" [argument_list] ")"` | `parse_class_modification` | `Modification::args` |
| `argument = element_modification_or_replaceable \| element_redeclaration` | `parse_class_modification` 内分派 | `ModArg` |
| `element_modification_or_replaceable = [each] [final] (element_modification \| element_replaceable)` | 同上 | `ModArg::each_/final_` |
| `element_modification = name [modification] description_string` | 同上 | `ModArg::path/sub/binding/string_comment` |
| `element_redeclaration = redeclare [each] [final] (short_class_definition \| component_clause1 \| element_replaceable)` | `parse_redeclare_in_modification` | `ModArg::is_redeclare/redecl`（`Id<Element>`） |
| `element_replaceable = replaceable (short_class_definition \| component_clause1) [constraining_clause]` | 同上 | 同上（`Element::is_replaceable`） |
| OMC/MLS 3.6：`break name` / `break connect(a, b)` | `parse_class_modification`（`Kw_break` 分支） | `ModArg::is_break/path/break_a/break_b` |

## B.2.6 equations / statements

| MLS 产生式 | 解析函数 | Absyn |
|---|---|---|
| `equation_section = [initial] equation {equation ";"}` | `parse_composition` + `parse_equation_list` | `ClassDef::equations` / `initial_equations` |
| `algorithm_section = [initial] algorithm {statement ";"}` | `parse_composition` + `parse_statement_list` | `ClassDef::algorithms`（`AlgorithmSection`） |
| `equation = (simple_expression "=" expression \| if_equation \| for_equation \| connect_clause \| when_equation \| component_reference function_call_args) description` | `parse_equation` | `Equation`（`EqKind`） |
| `if_equation = if expression then {equation ";"} {elseif ...} [else ...] end if` | `parse_equation`（`Kw_if`） | `Equation::branches`（`EqBranch::cond` 无效 = else） |
| `for_equation = for for_indices loop {equation ";"} end for` | `parse_equation`（`Kw_for`）+ `parse_for_indices` | `Equation::iters/body` |
| `when_equation = when expression then {equation ";"} {elsewhen ...} end when` | `parse_equation`（`Kw_when`） | `Equation::branches` |
| `connect_clause = connect "(" component_reference "," component_reference ")"` | `parse_equation`（`Kw_connect`） | `EqKind::Connect`（`lhs/rhs`） |
| `statement = (component_reference (":=" expression \| function_call_args) \| "(" output_expression_list ")" ":=" component_reference function_call_args \| break \| return \| if_statement \| for_statement \| while_statement \| when_statement) description` | `parse_statement` | `Statement`（`StmtKind`） |
| `for_indices = for_index {"," for_index}`；`for_index = IDENT [in expression]` | `parse_for_indices` | `ForIndex` |

方程/语句列表在 `end/elseif/else/elsewhen` 及段关键字处停止（`is_list_end`）。

## B.2.7 expressions

| MLS 产生式 | 解析函数 | Absyn |
|---|---|---|
| `expression = simple_expression \| if expression then expression {elseif ...} else expression` | `parse_expression` | `ExpKind::IfExp`（elseif 右嵌套进 `c`） |
| `simple_expression = logical_expression [":" logical_expression [":" logical_expression]]` | `parse_simple_expression` | `ExpKind::Range` |
| `logical_expression = logical_term {or logical_term}` | `parse_logical_expression` | `Binary(Op::Or)` |
| `logical_term = logical_factor {and logical_factor}` | `parse_logical_term` | `Binary(Op::And)` |
| `logical_factor = [not] relation` | `parse_logical_factor` | `Unary(Op::Not)` |
| `relation = arithmetic_expression [relational_operator arithmetic_expression]` | `parse_relation` | `Binary(Lt/Le/Gt/Ge/Eq/Ne)` |
| `arithmetic_expression = [add_operator] term {add_operator term}` | `parse_arithmetic` | `Unary(UPlus/UMinus)`、`Binary(Add/Sub/EWAdd/EWSub)` |
| `term = factor {mul_operator factor}` | `parse_term` | `Binary(Mul/Div/EWMul/EWDiv)` |
| `factor = primary [("^" \| ".^") primary]` | `parse_factor`（不可链式） | `Binary(Pow/EWPow)` |
| `primary = UNSIGNED_NUMBER \| STRING \| false \| true \| (component_reference \| der \| initial \| pure) function_call_args \| component_reference \| "(" output_expression_list ")" \| "[" expression_list {";" expression_list} "]" \| "{" array_arguments "}" \| end` | `parse_primary` | 字面量、`Call`、`CrefExp`、`Tuple`、`Matrix`、`Array`、`End` |
| `component_reference = ["."] IDENT [array_subscripts] {"." IDENT [array_subscripts]}` | `parse_cref` | `Cref`（`CrefPart::subscripts`） |
| `function_call_args = "(" [function_arguments] ")"`；`function_arguments = expression [for for_indices] \| named_arguments ...` | `parse_function_args` | `Exp::args/arg_names`；归约 → `ExpKind::Reduction` |
| `array_subscripts = "[" subscript {"," subscript} "]"`；`subscript = ":" \| expression` | `parse_array_subscripts` | `Id<Exp>` 列表（`ExpKind::Colon`） |
| `function_partial_application = function type_specifier "(" [named_arguments] ")"` | `parse_primary`（`Kw_function`） | `Call` + `partial_fn` |
| 任意 primary 后的下标 `({1,2,3})[2]`、`f(x)[1]` | `parse_postfix` | `ExpKind::Subscript` |
| 描述：`description = description_string [annotation_clause]` | `parse_comment` / `parse_string_comment_opt` / `parse_annotation_opt` | `string_comment` + `annotation`（`Id<Modification>`） |

反解析（`src/absyn/unparse.cpp`）**不按优先级增删括号**（2026-09-17 起，ADR-004）：源码里的 `(e)` 已作为单元素 `Tuple`
入树（同 OMC `Modelica.g:1856-1861`），反解析只打印树里有的括号；运算符间距、Real 字面量拼写、字符串原文、
`elseif`/`else if` 的区分都逐字对齐 OMC 的 Absyn dump（`AbsynDumpTpl.tpl`）。v2 曾按优先级补最少括号，那套规则已删除。

## ymc 跟随 OMC、偏离 MLS 字面的地方（来源：Modelica.g 与 testsuite 实跑）

| 构造 | MLS 字面 | OMC / ymc 行为 | 依据 |
|---|---|---|---|
| 类级 `annotation(...)` 位置 | 只能在 composition 末尾 | 可夹在任何段的元素/方程之间 | `flattening/.../Faculty5.mo`、`ElectrolytesT2Total.mo`（status correct） |
| 实数 `.13E2` | `UNSIGNED_NUMBER` 需整数部分 | 接受无整数部分 | `Modelica_3_Lexer.g`；`declarations/FloatingPoint.mo` |
| `$` 在标识符里 | `NONDIGIT` 不含 `$` | `$overload(F,G)`、`$cpuTime` 可解析（ymc 统一放宽为标识符字符） | `scodeinst/FuncOverload*.mo`（correct） |
| `replaceable type T = R extends TwoPin;` | 约束子句只有 `constrainedby` | 2.x 的 `extends` 写法也当约束子句 | `extends/GenericMicroCircuit.mo` |
| `f(i).y` | `primary` 不允许调用后取字段 | 接受 | `others/DotOperator.mo` |
| `({1,2,3})[2]`、`f(x)[1]` | 只有 cref 可带下标 | 任意 primary 后可下标 | `scodeinst/SubscriptedExp*.mo` |
| `import A.{c, e = d}` | `import_list = IDENT {"," IDENT}` | 组导入里可改名 | `mosfiles/GroupImport.mo` |
| `pure(f(x))` | 3.6 有 `pure` 算子 | 当函数名解析 | `scodeinst/FuncBuiltinPure1.mo` |
| `assert` | 不是保留字（B.1 列表没有它） | 普通标识符；`assert(...)` 是普通函数调用，也可作组件名 | OMC 词法器无 `assert` 记号；`Buildings 9.1.0/.../Validation/Assert.mo` 有 `Assert assert(...)` |
| `{}` | 文法允许空 `array_arguments`？ | **语法层拒绝**："Empty array constructors are not valid" | `arrays/EmptyArray.mo`（incorrect） |
| 修饰名带下标 `x[1] = 2` | 不允许 | 语法层拒绝（Missing token ')'） | `Modelica.g:955`；`arrays/ArrayModification1.mo` |
| `pure`/`impure` 关键字 | 3.3 起保留 | `--std=3.2` 时是标识符 | `openmodelica/parser/PureImpure3.mo` |
| 错误位置约定 | — | 无前缀元素首个组件名缺失 → 报在元素起点；其余报在出错记号；首尾类名不同 → 报在类头名字；缺 `end if` → 报在 `end` | `tools/parse_error_align.py` 23/23 |

## 未实现（有意）

- PDEModelica 扩展（`field`/`domain`，`-d=pdemodelica`）、MetaModelica（`-g=MetaModelica`）：范围外（方案 §1.4）。
- `--std` 目前只影响 `pure/impure`；其它版本差异（如 3.2 之前的 `annotation` 形式）未处理。
- 语义层检查（类型、作用域）一律不在 S1；S2/S3 做。
