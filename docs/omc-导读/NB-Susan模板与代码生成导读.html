一句话抓住主线：Susan 是一门"输出即返回值"的纯函数式模板语言——每个 template 编译成一个 Text → Text 的 MetaModelica 函数，文本一路线性穿过； C 代码里躲不掉的副作用（临时变量声明、前置语句）靠 & 文本缓冲区当"出参"传。

新后端不直接喂模板。NSimCode 先把 NBackendDAE 建成一套新的 SIM_CODE，再 convert 回旧的 SimCode.SIMCODE，之后模板层（SimCodeTV.mo + 所有 .tpl）对新旧后端一视同仁。
